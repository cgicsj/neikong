# 附件与校验

- 保留年度、单位代码、上报时间、项目序号、题目和原文件名。无论题面是否显示附件，均逐题打开「查看附件」。等待弹窗内的加载状态结束，再按清单分页逐行核对和下载。题面文件名或数量用于交叉核对，发现差异时记录对应项目和题目，并保留弹窗清单所列的原件。
- 刚打开时显示「暂无数据」可能是加载占位。自动采集只有在观察到加载状态结束且表格明确为空后，才确认「未上传」。未观察到加载完成信号、清单超时或遇到自动采集暂不支持的分页时，标为「附件清单待核」，回到该题的弹窗复核并补采。独立复读遵循同一判断。
- 按浏览器实际完成的下载核对来源、字节数和格式。多个原件同名且不能确定对应关系时，从题目清单逐件下载，完成后保存到独立编号路径。为每份原件保存 SHA-256，下载失败或归属不明时保留登记和原因。解包时先确认归属主体，拒绝绝对路径、目录穿越、链接和覆盖冲突。
- 优先提取可靠文字层。需要 OCR 时，先把扫描页或必要图像区域交给当前模型逐页识读。模糊内容放大或纠偏重读；仍不能辨认或当前模型无法接收图像时，用本地中文 OCR 补读并对照原图。表格保留行列对应，流程图保留节点和箭头。记录原件页数、已读页码、方式及缺项。逐页查看原图确认印章，盖章单位依据印面全称。看不清时按[归档格式](archive.md)记录待复核。
- 整体复核时重新打开同一版明细，独立比对项目序号、题目、评价和复核显示值以及逐题附件清单。保存复核时间和发现的差异。只有源读取完整、附件原件与识读覆盖完整且 HTML 链接有效，才标为「校验通过」。
- Windows 界面复制的字段可能带 CRLF。生成 HTML 时按 UTF-8 字节写出，防止将已有换行重复转换。

## 可选的页面采集辅助

当前页面 DOM 与已验证选择器匹配时，可在用户已登录且由工具控制的报送页面运行 `scripts/evaluation_list.js` 和 `scripts/evaluation_detail.js` 的浏览器函数，只读展示数据并执行已知查看、切页和下载控件。明细函数展开四个大类，按左侧目录顺序直接定位子项目，逐项校验选中节点与对应正文。浏览器工具应限定到当前单位评价复核页面，执行前确认目标筛选、明细身份和文件下载目录。通用 Agent 可以按同样流程通过可见界面采集。发生选择器、状态或下载差异时回到可见界面核对。

用 BrowserSkill 批量采集时，先运行名录函数并把返回的 `value` 保存成 `source/名录.json`。在同一浏览器会话回到列表后运行下列命令。可用 `--limit 1` 试采一家；采集器逐项写入本地记录，重跑时按名录从未采完的单位开始。下载启动后若结果未知，先核对浏览器和本地文件。

```text
python -X utf8 scripts/collect_browser.py "批次目录" --session "浏览器会话编号" --downloads "浏览器实际下载目录"
```

独立复读时运行同一命令，使用 `--verify` 并省略 `--downloads`。可用 `--unit 单位代码` 限定到指定行。先确认已回到同一查询列表、名录行的上报时间未变。确认缺件后回源逐题补采，校验报告会保留缺件条目。
