# 基层单位内控评价下载归档

请用户在可操作的浏览器中登录财政部统一报表系统，并确认具有「单位评价复核」查看与下载权限。准备可读写的本地目录、Python 3.9 或以上版本和能够处理 PDF、图片、办公文档的工具。仅执行筛选、查看、页签切换和下载。禁止保存、提交、退回、撤销复核或更新标记。

## 确定名单

1. 在「单位评价复核」确认评价年度和组织范围，选择「单位类型 → 基层单位」，点击「查询」。等待实际结果更新，检查结果行类型均为「基层」或「基层单位」。保留实际筛选条件与总数。
2. 翻页登记全部单位，按单位代码去重，并将名录总行数与系统总数对账。按行检查**操作列**是否包含独立的「更多」控件。包含的纳入明细采集，即使上报或复核状态不同。未包含的留在总名录并标记「未开展」。操作列无法读取时标记「开展状态待核」。
3. 从同一单位代码行进入「查看明细」，核对年度、单位名称、代码和已记录的上报时间。无明细、无权限或读取失败时写明原因。先试采一家有附件的单位，再按名录逐家处理。

## 采集明细

1. 点击「基本信息」，保留各组行列和系统显示值，包括只读字段、空值及预填值。
2. 点击「评价指标打分」，展开左侧「一、组织层面内部控制」「二、业务层面内部控制」「三、内部监督」「四、补充指标」，按系统目录登记所有子项目并与总页数对账。可按「点击切换下一项」依次读取，跨类跳转失败时按左侧目录定位对应子项目。逐项确认所属大类、选中项目和右侧正文，再采集指标题干、实际评分及附件。去掉必填星号、灰色解释、扣分规则和上传说明。四个大类的全部项目均与目录对应后，才能标为采集完整。
3. 逐题打开「查看附件」，待弹窗清单加载完成后，再逐页核对及下载。只有确认加载完成且清单明确为空，才记录「未上传」。按[附件与校验](references/collection.md)处理。采集保持在这两个页签范围内。

## 归档与交付

- 每家保留 `record.json`、`attachments/`、`index.html` 及需要的复核底稿。按[归档格式](references/archive.md)生成 HTML，导航和正文按大类、子项目及具体指标分层。项目汇总只显示最终得分，每条指标题干下显示该题得分，附件识读正文直接显示。
- 交付前将名录、项目数、题目附件清单、原件和离线链接逐项对账。批次 HTML 仅列出开展评价的单位，通过单位名称进入详情。单位校验结果和缺项位置保存在本地 `verification.json`。
- 关闭本次打开的明细、附件弹窗和自动化窗口，保留用户原有页面及登录状态。实际填报内容、附件及校验记录仅保存到指定本地归档目录。
