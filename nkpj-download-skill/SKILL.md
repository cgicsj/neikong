# 基层单位内控评价明细采集

请用户在可操作的浏览器中登录财政部统一报表系统，并确认具有「单位评价复核」查看权限。准备可读写的本地目录、Python 3.9 或以上版本和可读取 PDF、图片及办公文档的工具。只读取和归档明细，不保存、提交、退回、复核或更改系统数据。

## 范围

- 查询列表仅用于确认年度、基层单位范围、单位名录和操作列是否包含「更多」。按用户指定的单位或数量进入「查看明细」。
- 每家单位只采集明细中的「基本信息」「评价指标打分」「补充说明」三部分。评价指标打分包括四个大类及全部评价项目，按系统目录顺序采集指标标题和实际选中的得分。
- 不从查询结果执行「批量下载报告」「批量下载附件」或其他批量操作；不导出系统报告文档或将报告打包成压缩包。
- 评价指标打分页内的附件，按题逐一打开「查看附件」，等待清单加载完成后核对并下载清单所列原件。只处理明细中这三部分实际关联的附件，不按题面猜测附件是否存在。将附件保存在本地并优先使用当前模型 OCR，保留逐页文字及印章核对结果。不得在查询结果批量下载附件。
- 「补充说明」只按该页实际显示内容采集；不扩展到其他页签、报告导出、批量报告下载或无关字段。

## 操作流程

1. 在「单位评价复核」确认年度和组织范围，筛选「单位类型 → 基层单位」并查询。逐页登记单位代码、名称和操作列状态，核对名录总数。仅把操作列包含「更多」的单位视为开展评价；按用户指定的范围选择单位。
2. 逐家从单位代码对应行进入「查看明细」，核对年度、单位名称、代码和上报时间。信息不匹配、明细不可见或读取失败时记录原因并停止该单位采集。
3. 采集「基本信息」页实际显示的分组、字段和值，包括空值。
4. 采集「评价指标打分」页。展开「一、组织层面内部控制」「二、业务层面内部控制」「三、内部监督」「四、补充指标」，登记全部子项目并与系统页数核对。逐项确认标题层级、指标题干和实际选中分值；去除必填星号、灰色解释、扣分规则和上传说明。对题目关联附件按上文逐题核对、下载和识读。
5. 采集「补充说明」页的实际显示内容、表格和字段值；如页面明确为空，记录为空，不补写解释。
6. 对照当前明细复核三部分的内容和附件清单，保留差异与缺项。不得把未取得内容标为完整。

## 归档

- 每家使用单位代码命名目录，保留 `record.json`、仅含评价指标页逐题附件的 `attachments/`、`index.html` 和 `verification.json`。批次目录保留筛选名录及批次 `index.html`。
- HTML 仅设置「基本信息」「评价指标打分」「补充说明」三个明细部分。评价打分按四个大类、评价项目和指标分层展示；项目显示最终得分，指标题干显示其实际选中分值；附件 OCR 纯文字直接展示，印章仅展示盖章情况、盖章单位及与填报单位是否一致。
- 所有报表、逐题附件、OCR 文字及核验记录只保存在用户指定的本地目录。不得提交或上传到 GitHub、云端或其他外部位置。
- 关闭本次打开的明细、附件弹窗和自动化会话，返回用户原有页面并保留登录状态。
