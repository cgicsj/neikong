# 汇总部门内控编报下载

在用户已登录的财政部统一报表系统中只查看和下载。默认范围为当前年度任务下账号可见的全部汇总部门，按用户指定调整年度、下级范围和上报状态。禁止触发退回、保存、提交或审核标记。

采集范围仅限「基本信息录入」和「部门内部控制情况」。跳过「部门汇总内部控制报告」预览页签及「批量下载报告」等系统独立报告入口。文件名含“部门汇总内部控制报告”、但在两页签题目下作为上传件出现的材料，按该题附件正常归档。

## 查询与采集

1. 进入「下级报送纵览 → 内控报告报送纵览」，先清除旧的上报状态或标记筛选。选择「单位类型 → 汇总部门」并点「查询」。确认结果行的单位类型为「汇总」或「汇总部门」，结果仍混有基层单位时重新筛选。
2. 登记筛选口径、总数和逐页名录。只给数量时按当前查询顺序取前 N 家并记录顺序。按报告年度、单位代码和主体类型识别记录，报送版本另记报送时间。遇到与本级单位同名的记录，以代码和主体类型识别汇总记录。
3. 逐行打开对应的「查看明细」，用单位名称、代码和主体类型核对身份。依次读取「基本信息录入」和「部门内部控制情况」，等待页签正文及附件数量加载完成。第二页签显示「单位内部控制情况」时，回列表核对是否误打开了基层单位。
4. 按界面顺序原样记录章节、题目、表格行列和值，包括文本框、富文本、下拉框、单选、多选、禁用控件、预填值和计算结果。选项保留显示文字。用户填写值与系统标题通过 HTML 层级、题目标题 `label` 和实际值 `value` 区分。
5. 每完成一个单位就保存采集记录和附件状态，再从「关闭」返回列表。中断后按年度、单位代码、报送版本及附件清单续跑。没有明细入口、无权限或加载失败的单位保留在名录并记录原因。

首次批量使用前，先完成一个汇总部门的抽查，确认两页签完整、题目与附件对齐、原件可打开。之后仍以每次现场可见控件为准。

## 附件与输出

对两页签逐题下载全部附件并按[附件下载与识读](references/attachments.md)提取全文和识读印章。需要 OCR 时先用当前模型逐页看图，模型无法接收图像或重读后仍不能辨认的区域，再用本地中文 OCR 补读。表格、流程图、手写文字和印面均需核对。

每部门建立独立目录，保存 `record.json`、`attachments/` 和 `index.html`。按[归档格式](references/archive.md)生成页面，沿用实际页签、章节和题目顺序。每题直接显示值及附件链接，附件全文直接展开。印章信息只显示盖章情况、印面确认的盖章单位、与填报单位是否一致。

## 验收与收尾

- 将批次名录、部门目录、每题附件登记数和实际下载逐项对账，核对原件非空、链接可离线打开、页数与全文处理页数一致。确认归档中没有系统独立生成的汇总报告页面或其导出件。
- 批次总目录列出完整归档、部分完成和未采集的记录，并写明附件缺失、识读异常、印章待复核或值无法确认的具体部门与题目。
- 正常完成、失败或中断后都先保存和核验成果，再关闭本次打开的明细、预览、临时编辑器和自动化标签页。先处理「另存为」等模态对话框，确认关闭结果。保留用户原有标签页、窗口和登录状态。
- 无法关闭或只能保留部分成果时，说明具体窗口、保存状态和缺项，不把未核验内容标为完成。
