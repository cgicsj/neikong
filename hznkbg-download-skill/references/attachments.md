# 附件下载与识读

## 按题目核对下载

- 在「基本信息录入」核对签章扫描件及其他上传项。在「部门内部控制情况」逐题打开「查看附件」等入口，核对列表以及可能的分页。即使页面无附件数量，也打开入口检查。保存章节路径、题目、原文件名、显示序号、下载状态及原件的本地相对路径。原件同名时通过题目和文件序号区分。
- 用两页签的题目清单确定附件范围。独立导出的汇总报告及报告预览页内容不入档。文件名含「部门汇总内部控制报告」的封面或其他上传件，按两页签内的实际上传位置判断归属。
- 单位行「更多 → 一键下载附件」可用时优先批量下载并安全解包。核对包内单位身份，再用题目路径、文件名和数量与明细附件清单交叉核对。匹配不唯一、包内缺件或包为空时，回到对应题目逐件下载。仅包内可见的文件保留原件并注明「题目待核」。正文内容与题目看起来不符时，仍按系统中的实际关联归档，另记供审核核对。
- 等待浏览器完成下载，检查文件非空且能按实际格式打开，排除下载未完成、错误页或登录页。失败先核对下载列表、文件和页面提示再重试。ZIP 解包时拒绝绝对路径、目录穿越、符号链接和重名覆盖，保存成员路径供溯源。下载失败仍保留原附件登记和原因。
- 明细刚打开时，附件数量可能暂时显示为 0。等对应题目和附件列表加载完再确认无附件。批量下载前核对实际勾选的单位代码，下载后按单位代码和附件清单验包，确认是本次下载的归档原件。

## 全文提取

- 逐附件保留原件。PDF 每页提取可靠文字层，扫描页、图文混合页中的图像区域和乱码漏文字区域做 OCR。图片及多页图像逐页查看。Word、电子表格等有结构的文档直接提取正文和表格，并对嵌入图像做 OCR。
- 需要 OCR 时，先把原图或页面渲染图交给当前模型直接识读。表格保留行列对应关系，流程图保留节点、箭头方向和分支，手写文字按可辨部分转写。局部模糊时，可放大、纠偏或裁切后交给当前模型重读。
- 当前模型无法接收图像，或重读后仍不能辨认时，才对受影响的页或区域调用可用的本地中文 OCR。同页只补读缺失区域，保留已读清的内容。对照原图核对补读的文字，重点检查表格中的数字、流程图的指向、手写姓名和印面单位。仍无法辨认时，按实际位置标记「辨认不清」。
- 每页或每工作表记录页号或表名、方法、结果和提取的纯文字。合并文字层与 OCR 时去除重复段落，保留换行和表格行列。模糊处标记「辨认不清」，失败或不支持的页面列出原因。核对原件页数和处理页数。无文字层的扫描件需继续渲染和识读。可提取正文的 PDF 仍需检查原页面上的印章。
- 方法按实际记录为「当前模型识读」「本地 OCR」「当前模型识读＋本地 OCR 补读」或「文字层提取」等。续跑时可复用内容一致的已处理页，按原件字节或整页图像校验，保留当前原件的页码和附件关联。

## 印章识读

用当前模型逐页查看原页面或高分辨率渲染图。印面难读时先放大印章区域，按上述条件调用本地 OCR 补读印面文字。优先保留原图颜色，黑白扫描也检查。章名根据印面文字记录，支持圆弧文字、专用章和同一文件多枚章，分别登记页码及位置。正文落款、上传单位、文件标题或红色图形均不足以确认印章单位。

每份附件记录一个盖章状态，并在采集记录中逐枚保存单位、印面原文和位置。使用下列状态。

| 状态 | 使用条件 |
|---|---|
| 有可辨识印章 | 至少有一枚章，且能从印面读出单位。其他疑似或不清晰的章另列。 |
| 有章但单位待复核 | 能看出有章，印面文字不足以识别单位。保留可辨字和页码。 |
| 未见印章 | 已检查全部相关页，且画面清晰度足以观察。 |
| 无法判断 | 缺页、模糊、格式受限、疑似章或尚未完成检查，无法得出确定结论。 |

在采集记录中注明检查覆盖情况。存在可见电子印章时可按图像识读，只有实际验证过签名时才记录验证结果。

将印面可确认的完整单位名称写入 `organization`，原样保留可辨的印面文字至 `inscription`。同页多枚章分别比对。缺字、遮挡或只能读出部分机构名称时，单位写「待复核」，便于在 HTML 中显示「无法判断」。从印面可确认的上级机构、分支机构或内设科室名称保留全称，由审核人员结合题目判断该章是否合用。
